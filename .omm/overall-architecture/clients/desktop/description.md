spawn_sidecar in web/src-tauri/src/main.rs launches Python on a free localhost port with --exit-with-stdin. open_window waits for the listener or displays a failure page containing the server log location. stop_sidecar closes the ownership pipe, allows graceful shutdown, then kills the child if necessary. Rust also owns PTYs and external web-link opening. On Windows, shell() asks the running sidecar for GET /api/shell/terminal and builds the PTY command from the returned argv. This way the terminal follows the server's PowerShell choice, including a newly installed 7. Any response other than 200 becomes the terminal's error. On other platforms the PTY uses the default program.
