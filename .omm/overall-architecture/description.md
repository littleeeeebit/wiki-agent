wiki-agent is a local FastAPI application with a shared React interface, native Claude/Codex process adapters, persisted task workflows, and repository-scoped knowledge retrieval. tool/main/__main__.py enters main.app.main; app.py mounts the workflow routers and owns startup recovery and shutdown. Windows packages include immutable resources and an isolated Python runtime; common.paths sends writable state to per-user storage. main.onboarding owns prerequisite installation, official login and backup-first source import. Tauri verifies update payloads and coordinates backend and terminal shutdown before replacement. User requests start background workers whose streams can be reattached independently of execution. Source behavior places architecture maintenance on the PR checkout before an explicitly requested merge, and PR publication waits for a separate Review Loop request.
