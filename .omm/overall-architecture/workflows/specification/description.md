specs.save atomically replaces raw/specs/<repo>/<id>.json, rejects writes from a deleted or replaced task incarnation and publishes a summary invalidation. start calls checkout_idle and fork before moving the task into work. _check applies spec-update, validates done-report coverage, runs changed-path checks, and after extra_check hands over to pr_turn. pr_turn records the writing head. While its turn still holds the worktree, it builds the request text with pr_text.writing. That text is read off the diff for the pr.form form choice: code's baseline runs, and Jev's pick is recorded beside it. Only after that does pr_turn return the follow-up turn that asks the worker for its pr-summary. written checks the answer, asks once more if it fails, and opened publishes the PR. Missing reports or failed checks leave an actionable fault.
