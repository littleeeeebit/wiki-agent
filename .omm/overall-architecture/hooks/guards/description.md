Before checks run, codex_pretool.verdict and claude_pretool pass the payload through command_repair.repair. On a PowerShell 7 machine, _pwsh replaces only genuine external `powershell` invocations with `pwsh -NoProfile`. These are the literal, modernizable targets that shell.invocations reports after syntax-role, alias and function-binding resolution. On a 5.1-only Windows machine, the command is instead converted to the compatible ps5 gate form. The repaired command returns as updatedInput with notes for the agent. `command_repair.refusal` preserves the resolver's refusal text. Refusals for features that need PowerShell 7 name the `PowerShell 7 설치` control. An unresolved executable target is refused under either selected PowerShell version with a request to use a literal target. codex_pretool then chains host-boundary and deny checks, edit-as-diff checks, Markdown emphasis and English progress enforcement. Claude installs the corresponding checks separately through apply.py. A concrete refusal produces native hook output. Unexpected hook failures emit diagnostics and pass rather than terminating the session.
