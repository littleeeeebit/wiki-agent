Form choices are a separate kind of Jev decision. At these points Jev picks one form from a closed set that code offers, and code also has its own baseline answer. tool/main/decisions.py declares them in FORMS. There are two: pr.form (feature-with-behaviour-change, fix, refactor-no-behaviour, plan-document, files-only), reached from specs.pr_turn through pr_text.writing, and refactor.mode (preserve, simplify, rework), reached from refactor_survey.carded through moded. POINTS, OWNERS and coverage list both points for /api/jev as provisional. choose_form rejects a baseline that is not one of the point's forms. With mode off it asks nothing and returns the baseline. Otherwise, while the point is provisional, it returns the baseline at once. A daemon thread then asks Jev and records the pick, its probability, the option order, FORM_VERSION and the budget on that task's log through keep. Jev's form is used only when the mode is active, the point is named in ACTIVATED, and fitted(point, model) returns a result. If Jev doubts, defers, or the ask or the record fails, the baseline runs, never the host model. fitted reads eval/jev/branches/results/*.json, which git ignores and which tool/eval/branches.py writes. It takes the newest result by its recorded, timezone-aware ran_at and accepts it only if the model, FORM_VERSION and fixture digest all match, the Wilson lower bound is at least 0.90 and order agreement is at least 0.90. In pr_text.writing, form_facts reads the goal, criteria, artifact root, refactor mode and `git diff --numstat` from start_head. form_baseline turns those facts into code's form. The chosen form selects the matching section of tool/prompts/pr-write.md through guide. In refactor_survey.moded, the survey's mode stays on the card. When Jev's form differs, spec_shape checks the spec again under Jev's mode. If the spec holds, the card's refactor block gets jev_mode, which web/src/components/Blocks.tsx shows beside the survey's mode. Either way, decisions.outcome records executed or refused. The source does not show whether any result file currently passes this gate on a given machine.
