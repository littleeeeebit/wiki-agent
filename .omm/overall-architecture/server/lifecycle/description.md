runtime.server_owner holds an OS lock on raw/server.lock before app.lifespan calls loop.recover, planning.recover and survey.recover. On shutdown, close_turns sets runtime.stopping and joins any running PowerShell install thread (powershell.close_install). It then closes the loop, planning, refactor, work, agent and query owners. Watchers, the poll thread and the mobile companion stop before the lock is released. While stopping is set, POST /api/shell/install refuses to start. A second server cannot recover workflows while another owns them.
