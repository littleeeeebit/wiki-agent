architecture.write_nodes validates the complete path hierarchy and every described diagram child before publication. It rejects symlinks, escaped paths and reserved Mermaid node IDs, seeds a temporary OMM tree from existing documents and native metadata, then runs individual omm writes for changed fields. Owned obsolete descriptions and diagrams are pruned in staging; metadata-only obsolete elements use native omm delete. Because native deletion does not fix parent registries, the writer reconciles children from retained staged directories before validation and publication. Maintainer-only elements remain. Publication includes native metadata history and changed generated fields, but never restores a staged copy over an existing maintainer field or binary asset. Temporary CLI Git provenance points at the actual repository. Unchanged fields keep their metadata. .omm/analysis.json records generated ownership; obsolete empty owned elements are removed locally only after staged validation. Invalid analysis leaves the previous architecture intact.
