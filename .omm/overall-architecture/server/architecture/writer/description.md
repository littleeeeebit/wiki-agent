architecture.write_nodes validates the complete path hierarchy and every described diagram child before publication. It rejects symlinks, escaped paths and reserved Mermaid node IDs, then runs one omm write per field in a temporary directory and omm validate before replacing changed target fields. Existing maintainer context, constraints and notes survive. .omm/analysis.json records generated ownership; obsolete owned descriptions and diagrams are removed while notes remain. Invalid analysis leaves the previous architecture intact. This writer publishes local files only.
