architecture.write_nodes validates the complete path hierarchy and every described diagram child before publication. It rejects symlinks, escaped paths and reserved Mermaid node IDs, seeds a temporary OMM tree from the existing documents and native metadata, then runs one omm write per changed field and omm validate. Publication includes native meta.yaml history, timestamps, counters and parent children alongside changed fields; temporary CLI Git provenance points at the actual repository. Unchanged fields keep their metadata. Existing maintainer context, constraints, notes and non-document assets survive. .omm/analysis.json records generated ownership; obsolete owned descriptions and diagrams are removed while notes remain. Invalid analysis leaves the previous architecture intact. This writer publishes local files only.
