tool/common/shell.py is the one version-aware boundary for PowerShell text and launches. detect() probes `pwsh` (major 7 or higher) and `powershell` (5.1) once with `$PSVersionTable`, and probes again only on refresh. On refresh it also checks the standard `ProgramFiles/PowerShell/7/pwsh.exe`, because an installer cannot change the running server's PATH. chosen() picks the highest major version and raises Refusal naming the `PowerShell 7 설치` control when none is found. resolve() renders entries from common/shell_catalogue.COMMANDS in the `pwsh7`, `ps5` or `bash` form. For gate and registered-check it inserts `&` into legacy quoted executables through invoked(), and for ps5 it rewrites chains through ps5_chains(). It refuses 7-only constructs (seven_only) in the ps5 form. launch() wraps the line in a UTF-8, exit-code-preserving script for runtime.gate, and terminal() supplies the PTY argv. main/powershell.py exposes GET /api/shell/terminal and POST /api/shell/install. The install route accepts only the local screen, only on Windows and not while runtime.stopping is set. Without winget it returns shell.DOWNLOAD and a reason. Otherwise it runs the `install-powershell` catalogue entry through runtime.gate on a background thread with a 15-minute limit. runtime.gate_output streams the output into `_install`, and each update puts a `connect` event on work.feed. The run ends with detect(refresh=True). connect.py includes powershell.status() (shell.status() plus winget availability) in GET /api/connect and shell.status() in each project row. Invocation discovery (shell.invocations) uses powershell_syntax.command_position for syntax role, with hashtable context checked before generic statement boundaries. powershell_aliases.Aliases and powershell_functions.Functions then resolve declared alias and function bindings. Functions reads splatted arguments (`@name`) through powershell_splats.parameters, which decodes only a literal parameter collection bound before the call and otherwise raises Refusal. A target whose binding cannot be proved is classified unresolved; nested_commands refuses it. command_repair._pwsh uses that discovery to modernize only literal external `powershell` calls, leaving same-named aliases and functions alone. shell_lint.py, registered from lint.py, rejects uncatalogued PowerShell instructions.
