tool/common/shell.py is the one version-aware boundary for PowerShell text and launches. detect() probes `pwsh` (major 7 or higher) and `powershell` (5.1) once with `$PSVersionTable`, and probes again only on refresh. On refresh it also checks the standard `ProgramFiles/PowerShell/7/pwsh.exe`, because an installer cannot change the running server's PATH. chosen() picks the highest major version and raises Refusal naming the `PowerShell 7 설치` control when none is found. resolve() renders entries from common/shell_catalogue.COMMANDS in the `pwsh7`, `ps5` or `bash` form. For gate and registered-check it inserts `&` into legacy quoted executables through invoked(), and for ps5 it rewrites chains through ps5_chains(). It refuses 7-only constructs in the ps5 form. launch() wraps the line in a UTF-8, exit-code-preserving script for runtime.gate, and terminal() supplies the PTY argv. main/powershell.py exposes GET /api/shell/terminal and POST /api/shell/install. The install route accepts only the local screen, only on Windows and not during shutdown. Without winget it returns the official download URL and a reason. Otherwise it runs the `install-powershell` catalogue entry through runtime.gate on a background thread with a 15-minute limit. runtime.gate_output streams the output into `_install`, and each update puts a `connect` event on work.feed. The run ends with detect(refresh=True). connect.py includes powershell.status() in GET /api/connect and shell.status() in each project row. Invocation discovery (shell.invocations) uses powershell_syntax for command position, plus powershell_aliases and powershell_functions for binding. command_repair uses that discovery to modernize genuine external `powershell` calls. shell_lint.py, registered from lint.py, rejects uncatalogued PowerShell instructions.
