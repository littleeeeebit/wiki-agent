앱 실행, 내 프로젝트에 규칙 붙이기, 휴대폰 연결은 서로 따로예요. 하고 싶은 것 하나만 해도 돼요. 모델 사용량은 각자 로그인한 Claude Code나 Codex 계정에서 나가요.

  1. A앱에서 묻고 맡기고 싶어요데스크톱 앱을 설치하고 띄워요. ②~⑤ 페이지의 기능이 전부 여기 있어요.setup_chat ↓
  2. B내 프로젝트에서 에이전트가 규칙을 읽게 하고 싶어요앱 없이 훅만 붙여요. ① 페이지의 기능이에요.setup_agents ↓

A데스크톱 앱

설치하고 창 띄우기

필요한 것: Git, Python 3.11 이상, Node.js 22.12 이상, Rust(창을 빌드할 때), 그리고 본인 계정으로 로그인한 Claude Code나 Codex CLI 중 하나예요. 둘 다 깔 필요는 없어요.

  1. 저장소 받기 
    git clone https://github.com/littleeeeebit/wiki-agent.git
cd wiki-agent
  2. 설치하고 내 계정으로 로그인하기쓸 CLI에 맞춰 하나만 실행해요. .venv에 패키지를 깔고 화면을 빌드한 뒤, 로그인이 안 돼 있으면 공식 로그인 창을 열어요. 
    python tool/setup_chat.py install --agent codex   # 또는 claude, both
    프로젝트 목록은 위키 폴더의 상위 폴더에서 찾아요. 다른 곳에 있으면 --workspace "D:/작업 폴더"를 붙여요. 공백과 한글 경로도 돼요.
  3. 지도 파일 만들기처음 한 번, 그리고 규칙을 고친 뒤마다 해요. 
    .venv/Scripts/python tool/graph.py   # macOS·Linux: .venv/bin/python
  4. 한국어 번역 키 넣기 (선택)위키 폴더에 .env를 만들고 Gemini 키를 적어요. 키가 없으면 번역 없이 영어 원문이 그대로 나와요. 
    GEMINI_API_KEY=여기에-본인-키
  5. 실행하기 
    .\tool\app.cmd        # Windows
tool/app.command      # macOS·Linux
    처음엔 창을 빌드하느라 몇 분 걸려요. 창을 닫으면 서버와 에이전트도 같이 꺼져요. 창 없이 브라우저로 쓰려면 python tool/main을 실행하고 http://127.0.0.1:8787을 열어요.
  6. 첫 작업 맡겨 보기왼쪽에서 프로젝트를 고르고, 다음 작업 포커스에서 후보를 달라고 해요. 되묻는 선택지에 답하면 명세 카드가 나오고, [시작]을 누르면 에이전트가 작업 브랜치에서 일을 시작해요. 자세한 흐름은 ② 맡기기에 있어요.

작업 에이전트는 작업 브랜치에서 전체 권한으로 일해요. 파일을 쓸 때마다 허락을 기다리지 않으니, 중요한 변경은 커밋해 두고 쓰세요.

새 버전이 나오면 왼쪽 아래에 카드가 떠요. [업데이트]를 누르면 받아서 다시 빌드하고, [다시 시작]으로 창을 새로 열어요. 계정 바꾸기와 문제 해결은 docs/chat-setup.md에 있어요.

B규칙 붙이기

내 프로젝트에 규칙 붙이기

필요한 것: Python 3.11 이상, Git, Claude Code나 Codex CLI예요. Windows라면 Claude 훅에는 Git Bash가, Codex 훅에는 PowerShell이 필요해요. 명령은 모두 위키 폴더에서 실행해요.

  1. 훅이 쓰는 패키지 설치 
    python -m pip install -r requirements-hooks.txt
  2. 대상 프로젝트에 .wiki/adapter.toml 만들기그 프로젝트의 실제 검사 명령으로 채워요. adapters/example.toml은 가짜 예시예요. 
    agents = ["claude", "codex"]

[slots]
review_dir   = "artifacts/review"
gate_cmd     = "python -m pytest"
live_cmd     = "confirm the real events in a new session"
server_stop  = "Ctrl+C in the terminal that started it"
scratch_dirs = "artifacts/"
  3. 위키 버전 고정하기위키 폴더에서 git rev-parse HEAD를 실행하고, 나온 40자를 대상 프로젝트의 .wiki/wiki-revision에 한 줄로 저장해요(UTF-8, BOM 없음, LF). 팀 전원이 같은 버전을 쓰는지 이걸로 확인해요.
  4. Codex를 쓴다면 훅 켜기대상 프로젝트의 .codex/config.toml에 이 항목을 더해요. 파일이 이미 있으면 덮지 말고 이것만 추가해요. 
    [features]
hooks = true
  5. 설치하고 확인하기하나만 쓰면 --agent claude나 --agent codex로 바꿔요. 
    python tool/setup_agents.py --project "../내-프로젝트" --agent both
python tool/setup_agents.py --project "../내-프로젝트" --agent both --check   # 읽기만 해요
  6. 새 세션에서 직접 확인하기--check 통과는 연결이 맞는지만 본 거예요. 새 세션을 열어 프로젝트와 훅을 신뢰한 뒤, 세션을 열 때 현재 상태가 오는지, 규칙을 묻는 말에 그 규칙이 붙는지 직접 봐요.

프로젝트나 위키를 옮겼다면 같은 명령으로 다시 설치해요. 저장소마다 설치하지 않고 이 PC 전체에 한 번 거는 방법도 있어요. 전체 절차는 docs/hooks-setup.md에 있어요.

C휴대폰

밖에서 휴대폰으로 이어 보기

  1. 외부 연결 켜기PC 앱에서 설정 → 휴대폰 → 외부 연결 켜기를 눌러요. 터널은 앱이 알아서 준비하고, 준비되면 연결 QR이 나와요. VPN이나 포트포워딩은 필요 없어요.
  2. QR 찍기휴대폰 카메라로 찍어 브라우저로 열어요. 작업 목록과 대화를 보고, 지시나 승인을 보낼 수 있어요. 안드로이드 앱은 선택이에요.

연결 링크는 5분 안에 한 번만 쓸 수 있어요. 그 링크를 연 사람은 이 PC의 작업을 조종할 수 있으니 남에게 보여 주지 마세요. PC와 앱이 켜져 있어야 이어져요.

폴더 지도

받은 저장소의 어디에 뭐가 있나요

operator/ · craft/규칙 페이지. 사람의 일하는 방식과 에이전트의 기술
skills/절차서. 리뷰 루프, 머지 후 정리, 회고, 디자인 한 바퀴, 마크다운 쓰기
tool/훅과 도구. 규칙 붙이기, 설치, 기록 세기, 위키 검사, 결정 기록, 자가 개선
tool/main/앱 서버. 위키 질문, 명세, 작업 브랜치, 리뷰 루프, 계획, 리팩터링, 휴대폰 연결
tool/translate/ 외한국어 번역(translate), 검색(search), Jev 결정(decision), 평가(eval)
web/ · android/앱 화면과 데스크톱 창, 휴대폰 앱(선택)
docs/운영 문서(영어). plans/는 계획, research/는 설계마다 남긴 조사
raw/대화 · 리뷰 · 측정 기록. git에 올리지 않아요

docs/ 문서는 대부분 영어예요. 앱의 위키 포커스에 한국어로 물으면 그 문서를 근거로 한국어로 답해요.
