# 한국어 미러 열기

에이전트는 영어로 말하고, 옆 화면에서 같은 말이 한국어로 뜬다.

화면은 두 면이다. 왼쪽은 대화 — 사람이 친 말과 에이전트의 산문과 도구 설명이
한국어로 쌓인다. 오른쪽은 명령과 수정 — 실제로 실행한 명령과 패치가 번역 없이
그대로 쌓인다.

## 무엇을 옮기나

| 옮기는 것 | 그대로 두는 것 |
| --- | --- |
| 에이전트가 쓴 설명 | 명령 (`Bash`) |
| 도구 호출에 붙은 한 줄 설명 | 패치 (`Edit`·`Write`·`apply_patch`) |
| | 사람이 친 말. 이미 한국어다 |
| | 도구가 뱉은 출력. 안 찍는다 |
| | 훅·스킬이 끼워 넣은 주입문. 안 찍는다 |

명령과 패치는 번역기 근처에도 안 간다. 번역된 명령은 더 이상 실행되는 명령이 아니다.

번역이 실패하면 영어 원문을 찍는다. 미러가 비는 것보다 영어라도 보이는 것이 낫다.

## 여는 법

미러는 위키 앱의 탭이다. 별도 서버가 아니라 `tool/chat.py` 가 같이 서빙한다.

| 어디 | 무엇을 |
| --- | --- |
| Windows | `tool\mirror.cmd` |
| macOS · Linux | `tool/mirror.command` |

`http://127.0.0.1:8787/#mirror` 가 열린다. 앱이 이미 떠 있으면 탭만 열고,
안 떠 있으면 띄운 뒤에 연다. 포트를 바꾸려면 `--port 9090`.

이미 채팅을 쓰고 있다면 왼쪽 목록의 **한국어 미러** 를 누르면 된다. 같은 화면이다.

## 다른 작업트리를 비추려면

화면 위쪽에서 고른다. 호스트(`claude`·`codex`)와 작업트리가 각각 드롭다운이고,
세션이 있는 작업트리가 최근 순으로 전부 들어 있다. 고르는 순간 미러가 그쪽으로
옮겨 가고 화면은 비워진다 — 옮기기 전에 오던 번역이 뒤늦게 도착해도 섞이지 않는다.

**한 저장소의 작업트리는 그 저장소 아래에 묶여 있다.** 디렉터리 이름은 어느
저장소 것인지 말해 주지 않는다 — 서로 다른 저장소가 둘 다 `pollock` 이라는
작업트리를 갖고 있었다. 어느 저장소의 체크아웃인지는 git 에게 묻고(`git rev-parse
--git-common-dir`), 목록은 저장소로 묶어 브랜치 이름으로 구분해 보여 준다.

Codex 셀이 하위 폴더(`web/` 같은)에서 열려 있어도 같은 작업트리로 친다.

작업트리를 지워도 호스트가 쓴 로그는 남는다. 없어진 디렉터리는 목록에서 빠지고,
미러가 그 작업트리를 보고 있었다면 가장 최근 작업트리로 알아서 옮겨 간다 — 안
그러면 다시는 한 줄도 안 늘어날 로그를 계속 들여다보고 있게 된다.

## 화면 없이 터미널로 보려면

빌드도 서버도 없이 한 저장소만 따라가려면:

```powershell
python tool/mirror.py --project .
python tool/mirror.py --host codex --project C:\path\to\other-repo
```

"파서가 뭔가 보고 있기는 한가" 를 가장 빨리 답하는 길이다. 멈출 때는 `Ctrl+C`.
경로를 잘못 주면 세션이 있는 저장소 목록을 찍어 준다.

## 어느 파일을 따라가나

인자 없이 돌리면 그 저장소에서 가장 최근에 쓰인 세션 파일을 잡는다.

| 호스트 | 세션 로그 | 저장소를 가리는 방법 |
| --- | --- | --- |
| Claude Code | `~/.claude/projects/<저장소 슬러그>/*.jsonl` | 디렉터리 이름이 체크아웃 경로다 |
| Codex | `<CODEX_HOME>/sessions/<연>/<월>/<일>/rollout-*.jsonl` | 첫 레코드의 `cwd` |

세션이 아직 없으면 그렇다고 말하고 기다린다. 그 호스트로 한 번 말을 걸면 파일이 생긴다.

Codex 쪽 `<CODEX_HOME>` 은 한 곳이 아니다. 기본은 `~/.codex` 지만 `CODEX_HOME` 이
그 자리를 옮기고, Orca 는 계정마다 따로 준다 —
`%APPDATA%/orca/codex-accounts/<계정>/home`. 미러는 셋을 다 뒤진다. 기본 경로만
보면 Orca 로 띄운 세션은 돌고 있는데도 "세션 없음" 이 뜬다.

`/clear` 가 새 세션 파일을 만들면 미러가 알아서 그쪽으로 옮겨 간다.

## 셀이 여럿이면 파일을 지정한다

한 저장소에 작업 셀이 둘 이상이면 "가장 최근" 으로는 대상이 안 갈린다.
다른 셀이 한 줄 쓰는 순간 미러가 그쪽으로 넘어간다. 따라갈 파일을 직접 준다.

```powershell
python tool/mirror.py --session ~/.claude/projects/C--Users-me-repo/<세션>.jsonl
```

`--session` 을 주면 파일이 고정된다. 새 세션 파일이 생겨도 안 따라간다.
화면에는 이 선택지가 없다 — 화면은 늘 가장 최근 세션을 따라간다.

## 안 뜰 때

| 증상 | 볼 것 |
| --- | --- |
| 아무것도 안 뜬다 | 위쪽 드롭다운이 맞는 저장소를 가리키는가 |
| 영어가 그대로 뜬다 | 번역이 실패한 것이다. `GEMINI_API_KEY` 가 있는가. `python tool/translate --usage` 로 이번 달 사용액이 한도(`TRANSLATE_MONTHLY_USD`, 기본 $5)에 닿았는지 본다 |
| 남의 셀이 뜬다 | 터미널에서 `--session` 으로 파일을 지정한다 |
| Codex 가 안 잡힌다 | 그 셀에서 한 번 말을 걸었는가. 롤아웃 파일은 첫 발화에 생긴다 |
| 화면이 아예 안 뜬다 | `npm --prefix web run build` 를 안 돌렸을 수 있다 |
